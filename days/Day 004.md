# Day 4: Transformers, Embeddings & Attention

## What I Observed

Changing the wording or context of a prompt can change how an AI responds.

## What I Learned

- LLMs use the **Transformer architecture** to process language.
- Text is converted into **tokens** before being processed.
- **Embeddings** represent tokens as numerical vectors.
- **Attention** helps the model determine relationships between tokens.
- **Self-attention** allows tokens to interact with information from other tokens in the context.
- These mechanisms help explain why context and word relationships matter so much.

## Key Takeaway

> An LLM doesn't process a sentence like a human reading a sentence. It converts text into numerical representations and uses mechanisms such as attention to model relationships between tokens.

## Red Teaming Connection

Understanding how Transformers process context helps explain why changes in wording, context, and instruction structure can influence model behavior.
