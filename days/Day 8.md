# Day 8: AI Agents & Tool Calling

## What I Learned

- Tools give AI systems external capabilities.
- Function calling allows an LLM application to invoke external functions.
- AI agents can use tools, observe results, and take further actions.
- Tool access creates additional security risks.
- Authorization should be enforced outside the LLM.
- Least privilege is important for AI agents.

## Key Takeaway

> Intelligence does not equal authorization.

## Red Teaming Connection

When an AI can use tools, a red teamer must evaluate not only what the model says, but what actions the system allows it to take.
