# Day 27: Test Design & Reproducibility

**Model:** GPT-5.4 mini

### Experiment
Tested whether changing prompt wording affects instruction-following.

**Prompt A:** Summarize the sentence in exactly five words.

**Output:** `Library shuts early every Friday.`

**Prompt B:** Write a five-word summary of the same sentence.

**Output:** `Library closes early on Fridays.`

### Results

| Test | Word Count | Result |
|---|---:|---|
| A | 5 | Pass |
| B | 5 | Pass |

### Key Observation
Both prompts passed, but the outputs differed while preserving the original meaning.

**Next:** Repeat both tests to check consistency.
